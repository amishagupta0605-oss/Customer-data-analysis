# 📊 Customer Behavior Data Analyst Portfolio Project

## 📌 Project Overview
This project demonstrates a comprehensive, industry-standard end-to-end data analytics workflow. It simulates the real-world responsibilities of a Data Analyst, transforming raw retail data into actionable business intelligence. 

The analysis covers the entire lifecycle: from data cleaning and exploratory analysis in **Python**, to deep-dive querying in **SQL**, and final interactive storytelling in **Power BI**.

### 🎯 Key Objectives
* **Data Engineering:** Clean, transform, and model raw datasets for analytical readiness.
* **Database Integration:** Bridge the gap between Python environments and SQL relational databases.
* **Business Intelligence:** Answer critical business questions regarding customer segmentation, loyalty, and revenue drivers.
* **Stakeholder Reporting:** Synthesize complex data into a high-impact dashboard and executive presentation.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python (Pandas, NumPy, SQLAlchemy)
* **Database:** SQL (MySQL / PostgreSQL / MS SQL Server)
* **Visualization:** Power BI
* **Analysis:** Jupyter Notebook, SQL Queries
* **Reporting:** Presentation Deck, GitHub

---

## 🔄 Project Workflow



### 1. Data Preparation & EDA (Python)
* **Exploration:** Initial audit of 3,900+ purchases to identify patterns and anomalies.
* **Cleaning:** Handling missing values in review ratings and correcting data types.
* **Feature Engineering:** Creating age groups, purchase frequency metrics, and customer segments.

### 2. Database Management (SQL)
* **Schema Design:** Loading cleaned data into a relational database.
* **Advanced Querying:** Writing optimized SQL to analyze:
    * Revenue splits by gender and age group.
    * Impact of shipping types on average order value (AOV).
    * Subscription status vs. customer loyalty.

### 3. Visualization & Insights (Power BI)
* Developing an interactive dashboard to track KPIs:
    * **Customer Segmentation:** Loyal vs. New vs. Returning shoppers.
    * **Product Performance:** Top-rated items (Blouses, Dresses, etc.).
    * **Strategic Metrics:** 12% higher spend identified in Express Shipping users.
